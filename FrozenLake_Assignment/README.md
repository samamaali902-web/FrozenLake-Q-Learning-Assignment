# FrozenLake Q-Learning Assignment

Environment: Gymnasium FrozenLake-v1 (4x4, deterministic `is_slippery=False`). Algorithm: tabular Q-learning implemented from scratch.

## Run (Windows PowerShell / VS Code terminal)
```powershell
python -m pip install -r requirements.txt
python main.py
```
Outputs: `q_table.npy`, `training_progress.png`, `agent_demo.gif`. The program also prints training and evaluation results.

## Notebook
Open `FrozenLake_Training.ipynb` in VS Code and choose your Python interpreter, then Run All.
